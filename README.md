# 🎵 AI 유아음악 수업안 생성기

## 1. 서비스 소개

AI 유아음악 수업안 생성기는
유치원 · 어린이집 교사와 유아음악 강사를 위한 AI 웹 서비스입니다.

사용자가 연령, 수업 시간, 주제 등을 입력하면
AI가 실제 수업에서 사용할 수 있는 유아음악 수업안을 만들어 줍니다.

수업 준비 시간을 줄이고,
더 쉽고 편하게 수업을 준비할 수 있도록 만들었습니다.

---

# 2. 주요 기능

### 🎼 AI 맞춤 수업안 생성

- 연령에 맞는 수업안 생성
- 수업 시간에 맞는 활동 구성
- 음악 개념 반영
- 활동 유형 반영
- 교육 접근법 반영
- 클래식 음악 추천

---

### 🎹 음악교육 교수법 반영

AI가 다음 교수법을 수업안에 자연스럽게 반영합니다.

- 오르프
- 달크로즈
- 유리드믹스

---

### 🎵 사용자 친화적인 화면

- 반응형 웹 지원
- 모바일 사용 가능
- 쉬운 입력 화면
- AI 결과 바로 확인

# 5. AI가 동작하는 순서

① 사용자가 정보를 입력합니다.

↓

② JavaScript가 서버에 요청을 보냅니다.

↓

③ Python이 AI에게 수업안을 요청합니다.

↓

④ AI가 수업안을 생성합니다.

↓

⑤ 결과를 화면에 보여줍니다.

---

# 6. 실행 방법

프로젝트를 다운로드합니다.

필요한 라이브러리를 설치합니다.

```
pip install -r requirements.txt
```

환경 변수를 등록합니다.

프로젝트를 실행합니다.

---

# 7. 환경 변수

AI를 사용하기 위해 OpenAI API Key가 필요합니다.

환경 변수 이름

```
OPENAI_API_KEY
```

※ 보안을 위해 API Key는 코드에 작성하지 않습니다.

# 🎵 AI 유아음악 수업안 생성기

## 1. 서비스 소개

AI 유아음악 수업안 생성기는 유치원·어린이집 교사와 유아음악 강사를 위한 AI 기반 웹 서비스입니다.

사용자가 대상 연령, 수업 시간, 수업 주제, 음악 개념, 활동 유형, 음악교육 접근법 등의 조건을 입력하면 AI가 실제 교육 현장에서 활용할 수 있는 유아음악 수업안을 생성합니다.

수업안을 처음부터 직접 구성해야 하는 교사의 준비 시간을 줄이고, 다양한 음악 활동 아이디어를 보다 쉽고 편리하게 얻을 수 있도록 제작했습니다.

### 타겟 사용자

- 유치원 교사
- 어린이집 교사
- 유아음악 강사
- 유아 대상 음악수업을 준비하는 교육자

---

## 2. 서비스 목적

유아음악 수업은 연령과 발달 수준뿐만 아니라 수업 시간, 음악 개념, 활동 방법, 악기와 교구, 음악교육 접근법 등을 함께 고려해야 합니다.

AI 유아음악 수업안 생성기는 이러한 조건을 사용자가 직접 선택할 수 있도록 하고, 입력된 정보를 바탕으로 도입부터 전개, 마무리까지 연결되는 수업안을 생성하도록 설계했습니다.

단순한 활동 추천이 아니라 교사가 실제 현장에서 참고할 수 있는 구체적인 수업 흐름을 제공하는 것이 목표입니다.

- 달크로즈

### 🔄 같은 조건으로 새 수업안 만들기

현재 입력한 조건은 그대로 유지하면서 이전에 생성된 수업안과 다른 새로운 수업안을 생성할 수 있습니다.

이전 결과를 참고하여 음악, 활동 방법, 교구 활용, 교사 발문과 수업 흐름 등이 반복되지 않도록 재생성합니다.

### ✏️ 조건 바꿔서 새 수업안 만들기

생성된 결과를 확인한 후 입력 화면으로 돌아가 기존 조건을 수정하여 새로운 수업안을 만들 수 있습니다.

사용자가 모든 조건을 처음부터 다시 입력하지 않고 필요한 부분을 변경할 수 있도록 구성했습니다.

## 10. AI 기능 동작 흐름

1. 사용자가 웹페이지에서 수업 조건을 입력합니다
2. JavaScript가 사용자의 입력값을 수집합니다
3. JavaScript가 `fetch('/api/generate')`를 통해 백엔드에 요청을 보냅니다
4. Vercel Serverless Function으로 실행되는 Python 코드가 요청을 받습니다
5. Python이 입력값을 검증하고 AI 프롬프트를 구성합니다
6. Python이 OpenAI API를 호출합니다
7. OpenAI가 조건에 맞는 유아음악 수업안을 생성합니다
8. Python이 AI 결과를 JSON 형태로 프론트엔드에 반환합니다
9. JavaScript가 응답을 받아 수업안 형태로 화면에 표시합니다

## 11. 실패 처리

AI 기능 사용 중 발생할 수 있는 상황에 대응할 수 있도록 실패 처리 기능을 구현했습니다.

### 필수 입력 누락

필수 입력값이 없을 경우 해당 정보를 입력하거나 선택하도록 사용자에게 안내합니다.

### API 오류

서버 또는 AI API 호출 과정에서 오류가 발생하면 오류 안내 메시지를 화면에 표시합니다.

### 응답 지연 및 타임아웃

AI 응답을 기다리는 동안 현재 처리 상태를 알 수 있도록 단계별 로딩 메시지를 제공합니다.

프론트엔드에서는 최대 240초까지 AI 응답을 기다리고 제한 시간을 초과하면 요청을 중단한 뒤 다시 시도하도록 안내합니다.

## 13. 실행 방법

### 1. 프로젝트 다운로드

GitHub 저장소에서 프로젝트를 다운로드하거나 clone 합니다.

### 2. 필요한 Python 패키지 설치

```bash
pip install -r requirements.txt
```

### 3. 환경 변수 설정

OpenAI API를 사용하기 위해 다음 환경 변수가 필요합니다.

```text
OPENAI_API_KEY
```

API Key의 실제 값은 소스 코드에 작성하지 않습니다.

### 4. Vercel 환경 변수 등록

배포 환경에서는 Vercel 프로젝트의 Environment Variables에 `OPENAI_API_KEY`를 등록합니다.

Python Serverless Function이 해당 환경 변수를 읽어 OpenAI API를 호출합니다.

---

## 14. 환경 변수로 API Key를 관리하는 이유

API Key를 HTML, JavaScript 또는 Python 코드에 직접 작성하면 GitHub 저장소나 개발 과정의 스크린샷 등을 통해 외부에 노출될 위험이 있습니다.

따라서 API Key는 코드와 분리하여 환경 변수로 관리합니다.

프론트엔드에서는 API Key를 직접 사용하지 않고 `/api/generate` 엔드포인트만 호출하며 실제 OpenAI API 호출은 백엔드 Python 코드에서 처리합니다.

---

## 15. Vercel Serverless Functions

이 프로젝트의 백엔드는 별도의 서버를 직접 운영하는 대신 Vercel Serverless Functions를 사용합니다.

`api/generate.py`가 AI 요청을 처리하는 백엔드 엔드포인트 역할을 합니다.

프론트엔드 JavaScript에서 다음과 같이 요청합니다.

```javascript
fetch("/api/generate")
```

요청이 들어오면 Vercel에서 Python 함수가 실행되고 OpenAI API 호출 결과를 프론트엔드에 반환합니다.

이를 통해 API Key를 브라우저에 노출하지 않으면서 AI 기능을 사용할 수 있습니다.

## 16. 보너스 기능

### ✨ Fade-up 마이크로 인터랙션

AI 수업안 생성이 완료되면 결과 영역이 자연스럽게 나타나도록 Fade-up 마이크로 인터랙션을 적용했습니다.

이를 통해 결과가 갑자기 나타나는 방식보다 자연스러운 화면 전환을 제공합니다.

### 🔄 재생성 UX 고도화

수업안을 다시 만들고 싶은 상황을 두 가지로 구분했습니다.

1. 같은 조건으로 다른 수업안을 생성하는 경우
2. 기존 조건을 변경하여 새로운 수업안을 생성하는 경우

두 개의 기능을 별도의 버튼으로 제공하여 사용자가 목적에 맞게 선택할 수 있도록 구성했습니다.

## 17. 개발 및 개선 과정

프로젝트를 한 번에 완성하는 방식이 아니라 실제 Vercel 배포 환경에서 기능을 반복 테스트하며 문제를 수정했습니다.

개발 과정에서 다음과 같은 문제를 확인하고 개선했습니다.

- AI 응답 지연 문제
- API timeout 설정
- AI 생성 중 사용자에게 진행 상태가 보이지 않는 문제
- 생성된 수업안의 가독성 문제
- 같은 조건으로 다시 생성할 때 기존 결과와 구분해야 하는 문제
- 조건을 변경하여 다시 생성하는 사용자 흐름 개선

코드를 수정한 후 Git으로 변경 내용을 관리하고 GitHub에 push한 뒤 Vercel에서 자동 재배포하여 실제 서비스에서 다시 테스트했습니다.
